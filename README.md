🛒 MERN Stack E-Commerce Application

A full-stack e-commerce web application built using the MERN stack (MongoDB, Express.js, React, Node.js) with modern tools and best practices.
The platform supports user authentication, product management, cart & checkout flow, and order handling.

🚀 Features

User authentication (Register / Login / Logout)
Role-based access (Admin & User)
Product listing & product details
Add to cart & cart management
Checkout & order placement
Order history
Admin dashboard
Manage products
Manage users
Manage orders
Responsive UI

🛠 Tech Stack

Frontend
React
React Router
TanStack Query (React Query)
React Hook Form
Tailwind CSS / ShadCN UI
Axios

Backend
Node.js
Express.js
MongoDB
Mongoose
JWT Authentication
